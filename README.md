# CODSOFT Frontend Development Internship — Tasks 1–3

This repository contains three separate projects built with HTML, CSS, and vanilla JavaScript.

## Folder structure
- `Task1-Portfolio/` — responsive personal portfolio website
- `Task2-Todo/` — to-do list with Local Storage, search, filters, priorities, due dates, categories, and dark mode
- `Task3-Expense-Tracker/` — income/expense tracker with Local Storage, summaries, transaction editing/deleting, and category filtering

## Run locally
1. Extract the ZIP file.
2. Open a task folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.
4. No build tools or external libraries are required.

## Personalize before publishing
- In Task 1, replace “Your Name”, the sample bio, skill levels, sample projects, email, and social links with your own details.
- Replace `Task1-Portfolio/resume.pdf` with your real CV before sharing publicly. The included CV is a clearly marked editable sample.
- Test each project in desktop and mobile browser sizes.
- For GitHub, create a repository named `CODSOFT_TASKSNO`, upload these files, and share the repository URL in the internship submission form when CodSoft sends it.
- For the required LinkedIn video, record a short screen demo of each project and include your GitHub repository link and `#codsoft` in the post.

Note: the contact form validates input in the browser and displays a demo confirmation. It does not send email because no backend/email service is configured.
